Chrome Extension

GitHub Enhanced View

Configure local enhancements for GitHub repositories.

Features

File label rules

Configure labels applied according to words in file names.

File filter rules

Hide files by their exact name or by using * and ? wildcard patterns.

Pattern examples: .gitignore *.lock vite.config.* tsconfig*.json

Local repository mappings

Connect GitHub repositories with their local directories.

Enter the repository as owner/repository and its absolute local path.

Windows example: D:\Development\GithubEnhancedView

Linux/macOS example: /home/user/projects/GithubEnhancedView
