# GitHub Enhanced View

GitHub Enhanced View is a local-first Chrome extension that improves repository browsing directly on GitHub.

It adds file-type icons, configurable labels and filters, file sizes, and optional buttons for opening mapped repository files in Visual Studio Code.

![GitHub Enhanced View](images/github-enhanced-view-banner.png)

## Main features

- File-type-specific SVG icons in the repository list and file tree
- Configurable filename labels
- Configurable filtering of generated and configuration files
- File sizes retrieved through the official GitHub API
- Optional fine-grained GitHub token support
- Secure local repository mappings for Visual Studio Code
- Local-only settings with no analytics or developer-controlled backend

## Get started

1. [Install the extension](getting-started/installation.md).
2. [Configure its features](getting-started/configuration.md).
3. Optionally configure a [GitHub API token](github-api.md) or [VS Code mapping](vscode-integration.md).
